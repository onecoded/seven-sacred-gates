# The Seven Sacred Gates

A chakra and dosha healing journey. Take the seven-gate assessment, receive a
reading, and work with what it surfaces.

**[Open the app](chakra-destiny.html)** — it is a single self-contained HTML file
and runs offline, straight from disk, with no server and no account.

Everything you enter stays in your own browser. There is no backend, no analytics,
and nothing is transmitted anywhere.

## What is here

| | |
|---|---|
| `chakra-destiny.html` | the whole app |
| `data/` | the question bank and seed content |
| `versions/` | preserved earlier eras of the app |
